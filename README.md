---

## 📖 Overview

Book Summary Web App is a lightweight frontend application designed to help readers quickly explore books before purchasing them.

The application provides:

- 📚 Book summaries
- 🖼️ Book cover images
- 🔗 External purchase links
- 💻 Clean and responsive interface

This project was developed using only frontend technologies and focuses on user-friendly navigation and presentation of book information.

---

## ✨ Features

- Browse multiple books
- Read concise book summaries
- View book cover images
- External links to purchase books
- Responsive interface
- Simple navigation
